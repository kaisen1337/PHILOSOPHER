
# PHILOSOPHER

**Simple project for the Dining Philosophers problem using C language**

## What is this?
- This is a school project for 42/1337 School.
- It shows how to solve the famous "Dining Philosophers" problem using threads (multi-tasking) and mutexes (for safe access).

## Main Features & Files
- Written in C language.
- Main files:
  - `main.c` — the main code for running the problem
  - `philo.h` — header file with all important definitions
  - Other `.c` files — different helpers (memory, printing, checking errors, etc.)
  - `Makefile` — helps you build (compile) the project easily

## How to Use

1. **Compile the project**
   - Open your terminal
   - Go to the project folder
   - Run:
     ```
     make
     ```
    This will create an executable file.

2. **Run the program**
   - After compiling, run:
     ```
     ./philo [arguments]
     ```
   - Example arguments (check main.c or project instructions for details).

## Who can use this?
- Coding beginners
- Students learning about threads and parallel programming in C
- Anyone interested in operating systems or solving classic CS problems
